# Pokémon TCG Pocket (PTCGP) 自动化指南

《宝可梦卡牌口袋版》（Pokémon TCG Pocket，应用包名 `jp.pokemon.pokemontcgp`）是基于 Unity 引擎构建的竖屏卡牌游戏。

由于游戏采用自绘渲染（Canvas/SurfaceView），安卓原生无障碍节点树（`android_tree`）无法获取游戏内卡牌、按钮等节点，**必须采用 100% 视觉感知（截图 + 坐标映射）** 驱动。

---

## 快速准备与状态检查

开始任何操作前，执行标准初始化：
```json
android_ready()
```
确认设备已连接且屏幕点亮。如果未在前台，启动游戏：
```json
android_launch_app(package="jp.pokemon.pokemontcgp")
```
> **提示**：游戏启动时若弹出“登录/轻触屏幕开始”或“公告/活动弹窗”，点击屏幕中央或关闭按钮跳过，直到进入游戏主界面（下方显示：卡包、对战、社交、菜单导航栏）。

---

## 双脑架构（Jev Fast-Loop 与主模型分工）

卡牌游戏包含大量的“动画等待”和“关键决策”。推荐使用 **双脑分工架构**：
1. **小脑（Jev / 快速分类器，毫秒级，运行在 `codemode` 循环中）**：
   - 负责高频状态探测：判断“开包动画是否结束”、“是否出现轻触屏幕提示”、“是否轮到我的回合”、“对战是否已结算”。
   - 免去每次循环都把整张大图上传给昂贵大模型的漫长往返延时。
2. **大脑（主视觉大模型）**：
   - 负责复杂局势决策：评估当前 5 张手牌、我方前台/后排状态与敌方宝可梦属性，规划出牌与攻击策略。

## 模式一：日常全自动托管（Daily Automation）

日常任务包含三大流水线：**免费开包**、**得卡挑战**、**领取任务与商店奖励**。

### 1. 自动开卡包（Booster Pack Opening）
1. **入口**：在主界面点击底部的 **「开包」** 图标（通常在左下角或主页中央卡包展示位）。
2. **开包资格判断**：
   - 观察卡包沙漏/计时器是否显示「可开启（Open Now / 免费）」；
   - 若沙漏可用且满足开启条件，点击进入选包界面。
3. **选包与拆包动作**：
   - 点击选择卡包（喷火龙/超梦/皮卡丘/新系列包）；
   - **撕开卡包手势**：卡包居中展示时，使用平滑向下滑动（或横向划开）模拟撕包动作：
     ```json
     android_swipe(from_x=270, from_y=320, to_x=270, to_y=680, duration_ms=400)
     ```
4. **抽卡翻牌与跳过**：
   - 连续点击屏幕中央偏下位置（或右上角的「全部翻开 / Skip」按钮）；
   - 出现 5 张卡牌展示后，点击屏幕任意位置跳过特写；
   - 如遇新卡或高罕卡（ex/全图/实景卡），等待动画结束后点击「确定 / 下一步」返回。

---

### 2. 得卡挑战（Wonder Pick）
1. **入口**：在主界面点击 **「得卡挑战」**（通常在主页中部的飞天皮卡丘/卡牌图标区域）。
2. **挑战挑选**：
   - 观察列表中是否有「免费挑战（Free Pick）」或消耗 1~2 体力且含有急需卡牌的格子；
   - 点击选定挑战项目，进入洗牌界面。
3. **洗牌与选牌**：
   - 等待 5 张卡背面朝上完成洗牌动画（约 3 秒）；
   - 点击 5 张背向卡牌中的任意一张（例如中间位置 `(x=270, y=550)`）；
   - 翻牌展示获得卡牌，点击空白处或「确定」收下。

---

### 3. 每日任务与商店免费礼包领取
1. **每日任务**：
   - 观察主界面右侧或右上角的「任务（Missions）」图标是否有红点；
   - 点击进入任务中心，点击 **「一键领取（Claim All）」**（通常在界面右下角）；
   - 点击弹出的获得奖励确认框。
2. **商店每日礼包**：
   - 点击底部导航栏进入 **「商店（Shop）」**；
   - 滑动到每日免费道具栏位（每日免费开包沙漏/得卡沙漏）；
   - 点击并确认免费领取。

## 模式二：PVE 单人对战挂机（Solo Battle）

在「对战」->「单人对战（Solo）」模式中，AI 对手固定，非常适合自动化刷经验、刷商店对战券和完成熟练度任务。

### 1. 对战界面布局基准（标准竖屏，以截屏相对坐标为例）

```
┌─────────────────────────────────┐
│ [敌方后排/备战席 1-3]          │
│ [敌方战斗宝可梦 Active]          │
├─────────────────────────────────┤
│ [我方战斗宝可梦 Active]  (中央)  │
│ [我方后排/备战席 Bench 1-3]     │
│ [能量区]              [回合结束]│
│ [我方手牌区 Hand Cards] (底部)  │
└─────────────────────────────────┘
```

* **我方战斗场（Active Spot）**：约居中偏下 `(x: 45%~55%, y: 52%~58%)`
* **我方备战席（Bench Spots）**：下方三格 `(x: 25%, 50%, 75%, y: 64%~70%)`
* **能量区（Energy Zone）**：左下角或左侧小圆盘 `(x: 15%, y: 78%)`
* **回合结束按钮（End Turn）**：右下角高亮圆钮 `(x: 85%, y: 78%)`
* **手牌展开区（Hand Area）**：底部边缘 `(y: 88%~98%)`

---

### 2. 标准对战动作优先级矩阵（每回合按序执行）

当状态识别为「**轮到我的回合**」时，按以下优先级执行决策：

1. **第一优先级：附能（Attach Energy）**
   - 检查能量区是否有生成的能量（每回合 1 个）；
   - 将能量从能量区拖拽至**前台战斗宝可梦**或需要养蓄大招的**后排核心宝可梦**：
     ```json
     android_swipe(from_x=80, from_y=750, to_x=270, to_y=540, duration_ms=300)
     ```
2. **第二优先级：放置基础宝可梦或进化（Play / Evolve）**
   - 上滑展开手牌栏；
   - 若备战席有空位且手牌有基础宝可梦（Basic），拖入备战席；
   - 若场上有可进化的对应一阶/二阶宝可梦，将手牌中的进化卡拖拽重叠至该宝可梦身上。
3. **第三优先级：使用物品与支持者卡（Trainers / Supporters）**
   - **大木博士（Professor's Research）**：过牌，直接拖出使用；
   - **精灵球（Poké Ball）**：检索宝可梦，直接拖出使用；
   - **伤药（Potion）**：拖拽至受伤的前台宝可梦；
   - **娜姿（Sabrina）/ 速度强化（X Speed）**：视战况战术性使用。
4. **第四优先级：发起攻击（Attack）**
   - 点击我方前台战斗宝可梦；
   - 查看技能所需能量是否满足（若满足，攻击按钮会高亮发光）；
   - 点击技能名称并确认发动攻击。
5. **第五优先级：结束回合（End Turn）**
   - 攻击完毕后（或无法攻击时），点击右下角 **「回合结束」** 按钮；
   - 若有二次确认弹窗（例如“尚未附能是否结束”），点击确认。

---

### 3. 特殊状态处理

* **开局布阵阶段（Setup Phase）**：
  - 必须先指定一只基础宝可梦到战斗场（拖拽到中央光圈）；
  - 备战席可放 0~3 只；
  - 全部选定后点击「准备完毕（Done）」。
* **前台气绝换人（Active Knocked Out）**：
  - 我方前台倒下后，界面会变暗并高亮备战席；
  - 必须点击选择一只备战席宝可梦升至前台，点击确认出场。
* **胜负结算（Victory / Defeat）**：
  - 连续点击屏幕中心跳过计分板、经验结算、任务金币提示，返回关卡选择页。

## 自动化实战：`codemode` 纯 PHP 极速循环脚本

在 `codemode` 中，可以配合 Jev 做极速状态轮询。以下是推荐的执行模式：

```php
// @options: {"timeout_ms": 120000}
// 1. 获取当前状态截屏
$ready = $tools->android_ready();
$scale = [1.0, 1.0];

// 2. 循环监测对战/开包状态
for ($i = 0; $i < 10; $i++) {
    $obs = $tools->android_observe(['mode' => 'screenshot']);
    
    // 如果有 Jev 多模态分类器，可秒级判断当前界面分支
    // 无需每次都把大图送入主对话上下文
    $turnReady = true; // 由分类器或坐标检测
    
    if ($turnReady) {
        // 执行对应点击
        $tools->android_tap(['x' => 270, 'y' => 540]);
    }
    
    usleep(800000); // 间隔 800ms
}

return "批处理动作完成";
```

## 异常兜底与防卡死规则

1. **断线重连**：游戏偶尔提示「通信错误 / Retry」，点击中央「重试」通常能秒连。
2. **账号保护**：若遇到涉及 Nintendo Account 重新登录、付费购买宝可金红石（Poke Gold）等弹窗，**立刻停止自动化并提醒用户手动接管**。
3. **坐标容错**：由于不同手机屏幕比例（16:9 / 19.5:9 / 20:9）不同，UI 采用黑边填充或自适应拉伸。始终以每次 `android_ready` 返回的真实视口比例进行映射。
